# 6. Como Priorizar o Menor Número Possível de km / o Maior Número de Clientes Planejados?

Durante a otimização, você pode definir prioridades em **Configurações de Otimização** sob **Prioridades de Otimização** guia. Ajuste os seguintes parâmetros com base em seus objetivos:

* **Reduzir quilômetros**: Baixa / Normal / Importante
* **Reduzir janela de tempo de trabalho**: Baixa / Normal / Importante
* **Maximizar número de visitas**: Baixa / Normal / Importante
* **Usar o menor número possível de recursos**: Baixa / Normal / Importante

Essas configurações influenciam como o algoritmo de otimização equilibra suas restrições.\
**Dica:** Atribua diferentes níveis de prioridade a cada parâmetro para melhores resultados. Definir todas as restrições como “Importante” geralmente **não** produz resultados ótimos.
